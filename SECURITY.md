# Security Policy

[![Maatify Logger](https://img.shields.io/badge/Maatify-Logger-blue?style=for-the-badge)](https://github.com/Maatify/Logger)
[![Maatify Ecosystem](https://img.shields.io/badge/Maatify-Ecosystem-9C27B0?style=for-the-badge)](https://github.com/Maatify)

## Current Support State

The actively supported release line is `7.x`.

Security fixes are provided in the latest release within the supported `7.x` line. Users should upgrade to the latest available `7.x` version before reporting a vulnerability. Older release lines are not supported.

## Reporting a Vulnerability

Please report suspected package vulnerabilities privately to [support@maatify.dev](mailto:support@maatify.dev). Do not report a vulnerability in a public issue.

Include the affected package or context, reproducible details, the potential impact, and the relevant environment, version, or commit when known. No response time is promised.

## Scope

This policy covers vulnerabilities in the package's logging, redaction and file-writing behavior. Host authentication, authorization, deployment, log retention and infrastructure defects belong with the owner of the relevant Host.
